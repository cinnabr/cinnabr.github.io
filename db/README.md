# Cinnabar database

Run these in the Supabase SQL editor, in this order. Each file is safe to run again, except `cesium.sql` (it refuses to run twice).

1. `schema.sql`: profiles, files, sharing (Drive, Docs, Sheets, Slides)
2. `signup.sql`: account creation without a confirmation email
3. `sync.sql`: Quicksilver sync
4. `classroom.sql`: Classroom, Forums, Calendar
5. `forms.sql`: Forms and quizzes
6. `ratelimit.sql`: write limits per account (per minute and per day) and a daily sign-up cap, so no one account or script can flood Cinnabar. Safe to run again; run it after the others (and again after `cesium.sql`).
7. `cesium.sql`: Cesium, the class game platform, for school accounts only. Run once. It is generated by `tools/cesium_port.py` from `vendor/cesium/supabase/cesium_setup.sql`, so edit the generator, not the file.

All access control is Row-Level Security. The pages show "isn't set up on this Cinnabar server yet" until the matching file has been run.

## Testing locally

`test/` holds a minimal Supabase stand-in and assertion scripts for plain Postgres:

```
createdb cbt
psql -v ON_ERROR_STOP=1 -d cbt -f test/supabase_stub.sql -f schema.sql -f classroom.sql -f classroom.sql -f test/classroom_test.sql
createdb cbf
psql -v ON_ERROR_STOP=1 -d cbf -f test/supabase_stub.sql -f schema.sql -f classroom.sql -f forms.sql -f forms.sql -f test/forms_test.sql
```

Each prints `… tests ok` at the end, or stops at the first `FAILED:` line.

```
createdb cbc
psql -v ON_ERROR_STOP=1 -d cbc -f test/supabase_stub.sql -f schema.sql -f signup.sql -f classroom.sql -f forms.sql -f cesium.sql -f test/cesium_test.sql
```

## School accounts and Cesium

`profiles.edu` marks a school account. It is set by the "School account" box at sign-up, or later from the Cesium page. It is self-declared.
Every `ce_` table has a restrictive "edu accounts only" policy, and every Cesium RPC checks `ce_is_edu()`. The Cesium profile (student or teacher) is made by `ce_enroll`.
Cesium's admin panel needs one admin, set by hand:

```
update public.ce_profiles set is_admin = true where id = (select id from public.profiles where email = 'you@example.com');
```
